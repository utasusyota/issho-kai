# いっしょ買い v1.0

遠距離の家族とLINEビデオ通話で店頭の商品を一緒に選び、選んだ商品だけをJANコード＋写真で記録し、帰宅後にイオンネットスーパーで探すためのAndroidアプリです。

## 推奨運用
- 端末A: LINEビデオ通話専用（商品棚を映す）
- 端末B: このアプリ（JANスキャン・写真記録）

同一端末でビデオ通話とカメラを同時利用するとカメラ競合や通話映像の中断が起きることがあるため、2台運用を推奨します。

## 店頭
1. ご両親に商品を見てもらう
2. 「これ」と決まったら「JANバーコードを読む」
3. 自動で商品写真カメラへ
4. 撮影すると保存
5. 「次の商品をスキャン」

バーコード読取が使えない場合はJAN手入力、野菜などバーコードがない商品は写真だけで登録できます。

## 帰宅後
1. 「確認して注文する」
2. 商品写真・JAN・商品名・数量を確認
3. 「イオンネットスーパーで探す」
4. カートに入れた商品を「注文済み」にする

## データ
- 商品リストは端末内SQLiteに保存
- 写真はアプリ専用領域に保存
- 高画素写真は最大辺約1800pxへ縮小して容量・メモリ使用量を抑制
- JANの商品名はOpen Food Factsから取得できる場合のみ自動入力。取得できなくてもJAN＋写真で記録は継続可能

## APKをGitHub Actionsで作る
`.github/workflows/build-apk.yml` を同梱しています。GitHubのmainブランチに置くと、自動で `issho-kai-v1.0.apk` をビルドしてArtifactとして出力します。

## 対応
- Android 6.0（API 23）以上
- Google Play 開発者サービスを搭載したAndroid端末を推奨
